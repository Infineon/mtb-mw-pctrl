RFC (reference frame control)

General Description

Configuration macros for RFC block.

Portability macros for math operations used by RFC.

These macros can be defined in mtb_mw_pctrl_user_config.h to configure the RFC variant and optional features.

Variant selection macros:

  • RFC_USE_VARIANT_F32 (default)
    Selects the F32 variant for RFC block.

Performance optimization:

  • RFC_USE_INLINE
    Enable function inlining for RFC. Define this macro to inline the main processing functions for improved execution time. This trades code size for performance.

Optional features (disabled by default):

  • RFC_LPF_CAP_VOLTAGE_EN
    Enables low-pass filtering on outer-loop capacitor voltage measurements (Vc1, Vc2).
  • RFC_LPF_DQ_VOLTAGE_EN
    Enables low-pass filtering on inner-loop d/q-axis voltage inputs.
  • RFC_LPF_CURRENT_EN
    Enables low-pass filtering on inner-loop d/q-axis current feedback.
  • RFC_USE_COMMON_MODE_INJECTION
    Enables common-mode voltage injection in the modulation stage for improved DC-link utilization.
  • RFC_USE_CMSIS_DSP_LIB
    Uses CMSIS-DSP optimized trigonometric functions (sine/cosine) via rfc_port.h instead of standard math library.
  • RFC_USE_LOCAL_STORAGE
    Stores intermediate calculations on the stack instead of in the context structure, reducing context size.

These macros abstract the math backend used by RFC. By default, the C math library is used. If RFC_USE_CMSIS_DSP_LIB is defined, CMSIS-DSP functions are used instead.
